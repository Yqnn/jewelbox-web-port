# Jewelbox — Web Port

A web port of **Jewelbox**, aiming to be as accurate as possible to the original Mac OS Classic game.

**Play it:** [https://yqnn.github.io/jewelbox-web-port](https://yqnn.github.io/jewelbox-web-port)

---

## This project

This port brings Jewelbox to the browser with period-accurate visuals, sounds, and music where possible, so you can play it without emulation or vintage hardware.
